1. 시스템 용어 및 지갑/상태 분류 체계 (System Architecture)
1.1 용어 구별 기준 (Address vs Wallet vs Status)
  • Address (주소): 블록체인 온체인 상의 34자리 공개키 문자열 (예: T...). 유저별 1:1 발급 포인트.
  • Wallet (지갑): 내부적으로 Private Key / 서명 권한을 소유하고 온체인 인출/전송 트랜잭션을 실행하는 시스템 지갑 개체.
  • Deposit Status (입금 상태): 입금 트랜잭션의 검증 단계 및 제재 여부를 나타내는 DB 필드. (온체인 지갑 명칭 사용 금지)
1.2 지갑 분류 체계 (Wallets)
구분 지갑명 서명/관리 메커니즘 온체인 역할 및 인출 제약 조건
W1 Cold Wallet 오프라인 2-of-3 Multisig (Ledger) 인터넷과 완벽 격리. 자산 안전 보관 및 오프라인 키 세레머니 관리. (Phase 2 도입)
W2 Warm Wallet C-Level 다중 서명 (API 제한) Cold → Hot 유동성 공급 간 충격 완화 버퍼 지갑. 필요 시 CEX 입출금 창구.
W3 Hot Wallet 시스템 자동 서명 (백엔드 제어) Warm에서 보충 받고 Payout Wallet으로 전달하는 중앙 유동성 지갑. (2가지 전송만 허용)
W4 Payout Wallet 출금 전용 핫월렛 (System) [핵심 규칙] 유저 승인 출금 및 이자 지급 전용. 유저 입금 자금(Collection) 직접 유입 절대 엄금.
W5 Stage-1 Collection Wallet 1단계 집금 지갑 (System) 유저 입금 주소에서 $200 이상 누적 시 1차 집금되는 시스템 수집 지갑. (Phase 0 단일 집금 지갑)
1.3 입금 DB 상태값 매핑 체계 (Deposit Statuses)
DB Status 명칭 기존 폐기 용어 상태 정의 및 백엔드 처리 로직
Pending_Confirmation - TRON 블록 익스플로러 상 19 Block Confirmations 진행 중 상태. (DB 가산 전)
Screening Deposit Screening Wallet 19 컨펌 완료 후 4중 AML 및 보안 규칙 검사 진행 중 상태. (지갑 아님, DB 상태값)
Credited - 정상 검증 완료. 유저 DB 잔액(`users.balance`)에 100% 가산 및 집금 큐($200 이상) 등록.
Restricted Quarantine Wallet 의심/위험 자금 감지. 온체인 자금은 유저 주소 보관, DB 잔액 미가산, 집금 제외(Lock).
Restricted_Frozen - 관리자 검토 결과 영구 동결 확정. 유저 DB 잔액 미가산 유지, 집금 영구 제외.
⚠️ 파기 용어 명시: `Deposit Screening Wallet`, `Quarantine Wallet`, `Payout Reserve Wallet` 명칭은 기획서 및 개발 스펙에서 전면 파기/삭제되었습니다.

4.2 백엔드(Backend) 출금 API 핵심 계산 코드
def process_withdrawal_request(user_id, req_amount, withdraw_address):
    # 1. 최소 출금액 검증 ($10.00 USDT)
    if req_amount < 10.00:
        return raise_http_400("최소 출금 신청 가능 금액은 $10.00 USDT 입니다.")
    # 2. 유저 DB 잔액 검증
    user = get_user(user_id)
    if user.balance < req_amount:
        return raise_http_400("잔액이 부족합니다.")
    # 3. 유저 DB 잔액 차감
    user.balance -= req_amount
    # 4. 실제 온체인 송금액 산정 (고정 수수료 $1.00 차감)
    actual_transfer_amount = req_amount - 1.00
    # 5. $500.00 이상 고액 출금 수동 승인 전환
    if req_amount >= 500.00:
        create_withdrawal_record(user_id, req_amount, actual_transfer_amount, status="Pending_Admin_Approval")
        return response_success("고액 출금건으로 관리자 승인 후 송금됩니다.")
    # 6. $500.00 미만 즉시 송금 (Payout Wallet)
    else:
        tx_hash = send_trc20_usdt(from_wallet=PAYOUT_WALLET, to=withdraw_address, amount=actual_transfer_amount)
        create_withdrawal_record(user_id, req_amount, actual_transfer_amount, tx_hash=tx_hash, status="Completed")
        return response_success("출금이 완료되었습니다.")
