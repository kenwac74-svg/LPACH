🤖 LONGRISE AI - 기술 플랫폼

2. 5개 상품 완벽 가이드 (1/2)

💰 상품 선택의 핵심

고객에게 5개를 다 설명하지 마세요. 고객의 자금 규모에 맞는 1~2개만 추천합니다.
"$100~$500 있으면 Flexible이나 Basic, $1,000 이상이면 Premium이나 VIP 추천"

2.1 전체 상품 한눈에 보기

상품 가격 약정 월 수익률 CNYT 보너스 특징
Flexible $100 무약정 ~4% 없음 24시간 내 해지 가능
Basic $200 12개월 ~7% +2% 입문자 추천
Standard $500 12개월 ~9% +4% ⭐ 가장 인기
Premium $1,000 12개월 ~11% +6% 안정형 고수익
VIP $5,000 12개월 ~18% +10% 최고 수익률

2.2 상품별 세일즈 포인트

💚 Flexible ($100) - "부담 없이 체험"

  • 타겟: 처음 투자하는 사람, 의심 많은 사람
  • 장점: 언제든 해지 가능 (24시간 내 100% 환급)
  • 단점: 수익률 낮음 (~4%), CNYT 없음
  • 추천 화법: "일단 체험해보세요. 마음에 안 들면 바로 빼셔도 되니까요."

💙 Basic ($200) - "안전한 시작"

  • 타겟: 소액 투자자, 안정 추구형
  • 장점: 진입 장벽 낮음, CNYT 2% 추가
  • 단점: 수익률 보통 (~7%)
  • 추천 화법: "$200이면 부담 없잖아요. 월 $14 정도 들어오는데 나쁘지 않죠."

⭐ Standard ($500) - "가장 인기" (이것 먼저 추천!)

  • 타겟: 대부분의 고객 (80% 선택)
  • 장점: 가격 대비 최고 효율, 월 ~$45 수익
  • 단점: 없음 (밸런스형)
  • 추천 화법: "대부분 이걸 선택하세요. $500이면 월 $45 벌고, CNYT까지 받으니까 실속 있죠."
90% 고객에게 Standard를 먼저 추천하세요. "다들 이거 하세요"라는 말이 가장 강력합니다.

2.3 수익 계산 예시 (실전용)

"Standard $500 선택하면 얼마 벌어요?"

답변:
Standard는 월 약 9% 수익률이에요.
$500 × 9% = 월 $45 (USDT로 입금)
거기에 CNYT 보너스 4% = 월 $45 × 4% = $1.80 추가

총 월 $46.80 정도 들어옵니다.
12개월이면? $561.60 (원금 회수 + $61 순수익)

매일 UTC 06:00 입금되니까 커피값은 나오죠. 😊

수익 계산할 때는 "약", "~", "정도"를 꼭 붙이세요. "정확히 $45"가 아니라 "약 $45 정도"입니다.

2.4 복수 구매 안내

💡 Body Value 개념

하나의 계정에서 여러 상품을 구매할 수 있습니다.
예: Standard $500 + Premium $1,000 = Body Value $1,500

Body Value가 높을수록:
✅ 직급이 빨리 올라감
✅ 추천 수당 비율이 높아짐 (1% → 3% → 5% → 7%)
✅ Max-Out 한도가 늘어남 (10배수 룰)

2.5 상품 추천 플로우차트

① 고객 자금 확인
"편하게 투자할 수 있는 금액이 얼마 정도 되세요?"

② 금액별 추천
• $100~$300 → Flexible 또는 Basic
• $400~$800 → Standard (강력 추천)
• $900~$2,000 → Premium
• $2,000~$5,000 → Premium + Standard
• $5,000 이상 → VIP

③ 확신 주기
"대부분 이 금액대에서는 ○○○를 선택하세요. 가성비가 제일 좋거든요."

"다 사세요", "VIP가 무조건 좋아요" 같은 압박은 금지! 고객의 여유 자금 범위 내에서만 추천하세요.

3. 추천 수당 이해하기

💰 직접 추천이 가장 쉬운 수익!

내가 직접 추천한 사람이 가입하면 즉시 추천 수당을 받습니다.
이게 가장 빠르고 확실한 수익입니다.

3.1 추천 수당 테이블 (암기 필수)

내 Body Value 수당 비율 예시 (VIP $5,000 추천 시)
$100 ~ $999 1% $50
$1,000 ~ $2,999 3% $150
$3,000 ~ $4,999 5% $250
$5,000 이상 7% $350
나의 Body Value가 높을수록 추천 수당도 높아집니다.
그래서 처음 시작할 때 Premium이나 VIP를 권장합니다.

3.2 실전 계산 예시

시나리오: 내가 Standard $500, 친구에게 Premium $1,000 추천

Step 1: 내 Body Value 확인
→ $500 (Standard)

Step 2: 수당 비율 확인
→ $100~$999 구간 = 1%

Step 3: 수당 계산
→ $1,000 × 1% = $10 즉시 지급

✅ 친구가 가입하는 순간 내 계좌에 $10 입금됩니다!

❓ "그럼 나도 VIP $5,000 사면?"

만약 내가 VIP $5,000이면:
→ Body Value $5,000 = 7% 수당
→ $1,000 × 7% = $70 받음

차이: $70 - $10 = $60 더 받음!
→ 이게 Body Value를 높이는 이유입니다.

3.3 추천 수당 화법

"친구 추천하면 뭐 받아요?"

답변:
친구가 가입한 금액의 1~7%를 즉시 받으세요.
비율은 본인 투자 금액에 따라 달라집니다.

예를 들어 Premium $1,000 하신 분이
친구한테 VIP $5,000 추천하면
→ $5,000 × 3% = $150 바로 입금!

친구 10명 추천하면? $1,500이에요. 😊

4. 롤업 수당 완전 정복

⚠️ 가장 어려운 파트!

롤업 수당은 설명하기 복잡합니다. 고객이 물어보면 간단히 설명하고,

4.1 롤업 수당이란? (초간단 버전)

🎯 한 문장 정의

"내 하위 조직 전체가 버는 배당의 일부를 나도 받는 시스템"

쉬운 설명 (고객용)

내가 A를 추천하고, A가 B를 추천하고, B가 C를 추천했다고 해볼게요.

C가 매일 $10 배당 받으면:
→ B는 $10의 10% = $1 추가로 받음 (1단계)
→ A는 $1의 10% = $0.1 추가로 받음 (2단계)
→ 나는 $0.1의 10% = $0.01 추가로 받음 (3단계)

이게 25단계까지 이어집니다!
조직이 크면 하루에도 수백 명이 배당 받으니까
내 롤업 수당도 계속 쌓이는 거죠.

4.2 롤업 수당 핵심 룰

항목 내용
매칭 비율 직하위 배당의 10% 매칭
체감 구조 25대까지 10%씩 체감 (1대 10% → 2대 1% → 3대 0.1% ...)
실제 평균 대부분 15대까지만 조직 형성 (총 11.11% 추가)
지급 시점 하위가 배당 받을 때 즉시 계산되어 익일 지급
롤업은 "조직이 크면 클수록 유리"라는 것만 강조하세요.
복잡한 계산은 넘어가세요.
