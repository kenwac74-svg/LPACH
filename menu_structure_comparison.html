모바일 ↔ PC 메뉴 구조 핸드오프

모바일과 PC는 반응형이 아닌 별개 인터페이스이며, 구조 차이는 의도된 설계입니다. 표시 용어는 모바일 뷰 기준으로 통일합니다(PC가 모바일 라벨 채택). 내부 라우트 key·컴포넌트명은 변경하지 않고 표시 라벨만 적용합니다. 아래 결정 사항은 모두 확정입니다.

플랫폼 표기 — 모바일 하단 탭 5슬롯 · PC 상단 가로 네비 + 우측 유틸(아바타 드롭다운). PC 로고 클릭 = HOME 복귀.

5확정된 결정 사항

  1. 통일 라벨
    모바일 기준 — EARN · PLANS · NETWORK · MARKET · WALLET · ALL. PC가 채택. key·컴포넌트 불변.
  2. CRYPTO AI → EARN 페이지 완전 대체
    PC 좌상단 첫 메뉴 'CRYPTO AI' 페이지를 EARN으로 완전 대체. 기존 CRYPTO AI 소스는 백업 후 폐기 (리네임 아닌 페이지 교체).
  3. PC 계정 항목 = 아바타 드롭다운
    Profile·Security·Settings·Alerts·Docs·Support·Sign out → PC 우측 아바타 드롭다운. 참고: http://43.201.76.192:5173/login
  4. MARKET 위치 + 등급 배너
    PC: 상단 네비 4번 추가. 모바일: ALL ▸ Main 그룹 추가(탭 승격 아님). White Dragon 이상 유저는 Start Here 배너 → MARKET 배너로 교체.
  5. Start Here 노출 로직
    PC는 로그인 전/후 모두 노출(비로그인 HOME 배너, 신규 로그인 자동 이동). 모바일은 신규·무활동 팝업, 구매이력 있으면 미노출. (§4 매트릭스)
  6. PC HOME = 별도 기획
    PC 전용 HOME은 별도 페이지로 기획·개편 예정 (섹션 축소 + Start Here 큰 배너). 모바일엔 HOME 없음.
  7. ALL = 사이트맵
    모든 메뉴를 한 곳에서 보는 사이트맵 용도. Wallet 액션 중복 노출도 의도된 접근성 — 유지.
