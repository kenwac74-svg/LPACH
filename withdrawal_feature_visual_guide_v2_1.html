월렛 화면은 자산을 보여주고, 거래는 흐름별로 분리합니다.

v2.1 정책 기준의 핵심은 예치, 출금, 내부 전송, 패키지 구매, 보상 내역을 한 화면에 섞지 않는 것입니다. 사용자는 Wallet에서 현재 상태를 보고, 필요한 액션을 선택하고, 거래 결과는 성격별 히스토리에서 확인합니다.

02. User Flows

입금, 출금, 내부 전송은 같은 지갑에서 시작하지만 서로 다른 검증과 결과 화면을 가집니다.

Deposit

1
네트워크 선택지원 네트워크와 입금 주소를 표시합니다.
2
입금 확인블록 확인 후 Deposit Balance에 반영합니다.
3
패키지 구매 분리입금 자체가 자동 패키지 구매가 되지 않도록 안내합니다.

Withdraw

1
출금 가능 잔액 확인Withdrawal Balance만 외부 출금 대상으로 표시합니다.
2
주소와 수량 입력네트워크, 수수료, 최소 출금 기준을 함께 노출합니다.
3
상태 추적Pending, Processing, Completed, Rejected, Failed를 표시합니다.

Send

1
LONGRISE 사용자 검색이메일, UID, 지갑 식별자로 수신자를 확인합니다.
2
내부 전송 확인외부 지갑 전송은 Withdraw로 분리합니다.
3
즉시 기록완료 즉시 Transfer History에 표시합니다.

03. Balance Rules

자산 카드는 정책상 사용 가능 여부를 함께 보여주어야 오해가 줄어듭니다.

Withdrawal Balance

외부 출금과 내부 전송이 가능한 기준 잔액입니다. 출금 신청 중인 금액은 Pending Withdrawal로 별도 추적합니다.

Deposit Balance

입금 확인 후 먼저 반영되는 잔액입니다. 패키지 구매와 연결되지만, 입금 자체가 투자 실행으로 표현되면 안 됩니다.

Bonus USDT

정책 조건에 따라 전환, 사용, 제한이 달라질 수 있으므로 출금 가능 여부를 별도 라벨로 표시합니다.

Package Value

구매 상품의 표시 가치입니다. 일반 출금 가능 잔액처럼 보이지 않도록 Withdrawable 라벨을 분리합니다.

05. Mobile First

모바일에서는 잔액 카드, 액션 버튼, 히스토리 순서가 흔들리지 않아야 합니다.

Total Assets는 요약용이며, 출금 가능 금액은 Withdrawal Balance에서만 판단합니다.
Deposit, Withdraw, Send 버튼은 첫 화면 상단에 고정된 순서로 배치합니다.
Pending Withdrawal은 자산 카드에 섞지 않고 Transfer History의 상태값으로 보여줍니다.
외부 지갑 전송과 LONGRISE 사용자 간 전송을 같은 문구로 표현하지 않습니다.
서비스 제한 지역 안내는 가입 또는 거래 제한 화면에서 별도 고지합니다.
