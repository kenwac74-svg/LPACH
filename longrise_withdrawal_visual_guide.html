입출금 및 운영 통제
실무 액션 가이드

개발팀, 운영/CS팀, 최고 재무 관리자(Admin)가 매일 수행해야 할 입출금 처리 및 시스템 통제 업무를 명확히 규정하여 자금 사고를 원천 차단합니다.

1. 개발팀

상시 모니터링

  • 입금 감지 데몬: TRON/BSC 노드 연결 및 블록 동기화 딜레이 확인.
  • API & DB 헬스체크: 출금 대기열 DB 데드락 모니터링.
  • 롤백 검증: REJECTED / FAILED 출금 건 잔액 자동 반환 로직 1일 1회 점검.

이슈 대응

이중 지불 의심 시 긴급 보고, 출금 Queue 임시 중단, DB 로그 분석 및 수동 보정을 즉시 수행합니다.

2. 운영/CS팀

Daily Routine (10시, 16시)

  • 1차 심사: PENDING 리스트 확인 및 다계정/동일 IP 어뷰징 혐의자 색출.
  • 상태 변경: 어뷰저 REJECTED, 정상 건 PROCESSING 일괄 변경.
  • 리스트 추출: PROCESSING 상태 CSV를 최고 관리자에게 승인 상신.

CS 대응

한국 거래소 직접 출금은 금지하며, 해외 거래소 또는 개인 지갑 주소 사용을 안내합니다.

3. 최고 관리자

최종 집행 (11시, 17시)

  • 핫월렛 점검: 출금 전용 지갑 USDT, TRX, BNB 잔액 확인.
  • 최종 승인: 운영팀 CSV 검토 후 보안 환경에서 Batch Send 실행.
  • 2FA 필수: 출금 승인 및 주소 변경 시 Google OTP 인증.

보안 사고 대응

핫월렛 이상 징후 포착 시 콜드월렛 대피, 출금 기능 차단, 사내 공지 및 후속 조치를 즉시 진행합니다.
