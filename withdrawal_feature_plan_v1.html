Developer Spec v1.0 · Policy v2.1

LONGRISE Wallet 실제 개발사양서

본 문서는 월렛 목업 제작용 설명서가 아니라, LONGRISE 실제 플랫폼의 사용자용 WALLET 기능을 개발하기 위한 프론트엔드/백엔드 공통 개발사양서이다.

적용 범위: 사용자 월렛 화면, 입금, 출금, 내부전송, 자산 카드, 패키지 구매 잔액 처리, 히스토리, CNYT 및 Bonus USDT 표시 정책.

기준 정책서: Web3 패키지 플랫폼 입출금 및 운영 통제 정책서 v2.1 월렛기획반영

1. 핵심 개발 원칙

1.1 월렛은 순수 사용자 인터페이스

  • WALLET 화면에는 관리자 기능이 노출되면 안 된다.
  • 관리자 승인/반려 버튼, 운영자 상태 변경, Batch Send, Cold Wallet Sweep, Maintenance Mode, DB 구조, 개발자 주석, CS/Admin Tool 전용 정보는 금지한다.
  • 관리자 기능은 별도 Admin Tool에서만 구현한다.

1.2 기존 월렛 구조 대체

폐기 용어: My Wealth, LIQUID, STAKED, REWARDS 카드 단독 사용, LOCKED, GROWTH, Recent Activity

신규 구조: Wallet, Assets, Withdrawal Balance, Bonus USDT, Package Value, CNYT Tokens, Package History, Transfer History, Earn & Reward History

1.3 UI 언어

실제 사용자 UI는 영어를 기본으로 한다. 정책서와 개발사양서는 한국어로 작성하되, 화면 노출 텍스트는 영문 용어를 우선한다.

1.4 투자 플랫폼 표현 금지

Invest, Investment, Investment Plans, Invest Now는 사용하지 않는다. Packages, Activate, Earn, Package Value를 사용한다.

2. 화면 진입 및 내비게이션

  • 최상단 메뉴는 WALLET을 유지한다.
  • PC View Wallet 내부 사이드 메뉴: Assets, Deposit, Withdraw, History, Address
  • Package Buy는 월렛 내부 메뉴가 아니라 최상단 PACKAGES 메뉴에서 처리한다.
  • Quick Actions: Deposit, Withdraw, Send
  • Mobile View에서는 Wallet 제목 바로 아래 Quick Actions를 독립 배치한다.
  • Home / Invest / Wallet / Team 형태 신규 플로팅 메뉴는 추가하지 않는다.

3. 자산 카드 사양

3.1 Total Assets

총 자산 가치는 백엔드에서 내려주는 값을 기본으로 사용한다. Bonus USDT와 CNYT는 출금 가능 현금성 자산으로 오인되지 않도록 구분한다.

3.2 Withdrawal Balance

Withdrawal Balance: 1,023.00 USDT
Deposit Balance: 1,000.00 USDT
Earnings Balance: 23.00 USDT
  • 총액은 굵은 흰색
  • Deposit Balance는 일반 흰색
  • Earnings Balance는 노란색 또는 강조색, 굵게 표시
  • 버튼/태그는 Available
type WithdrawalBalance = {
  totalUsdt: string;
  depositBalanceUsdt: string;
  earningsBalanceUsdt: string;
};

프론트엔드는 total 값을 임의 계산해 원천값처럼 표시하지 않는다.

3.3 Bonus USDT

  • 패키지 구매에만 사용 가능
  • 출금 불가
  • 내부전송 불가
  • 카드 표시: Bonus USDT / Withdrawable / No
  • 카드 내부에 Package use only 같은 긴 문구 또는 상품권/액면/발행 단위 설명을 넣지 않는다.

3.4 Package Value

  • 활성 패키지 총 구매 금액
  • 카드 표시: Package Value, Status, Earning
  • 태그 또는 버튼: EARN
  • 클릭 시 Package History로 이동

3.5 CNYT Tokens

Total CNYT: 553 CNYT
Available: 53 CNYT
Staked: 500 CNYT

카드 내부 라벨에서 CNYT를 반복하지 않는다. Staked는 강조 색상을 사용할 수 있다.

4. 입금 프로세스

입금은 패키지 구매가 아니다.

  1. 사용자가 Deposit 진입
  2. 네트워크 선택
  3. 사용자별 입금 주소 확인
  4. 외부에서 USDT 입금
  5. 온체인 컨펌 완료
  6. Deposit Balance 증가
  7. Withdrawal Balance 총액 갱신
  8. 사용자가 별도 PACKAGES 메뉴에서 패키지 구매

Deposit 화면 필수 요소: Network selector, Assigned deposit address, QR code, Copy address, Deposit status, “Deposits are credited to your Withdrawal Balance. Packages are purchased separately.”

금지 요소: 패키지 선택 UI, 패키지 목표 금액, 입금 부족 패키지 보류 UI, 회사 집금 주소 또는 운영 지갑 주소 노출

5. 출금 프로세스

  • 출금 가능 잔액은 Withdrawal Balance만 사용한다.
  • Bonus USDT, Package Value, Staked CNYT는 출금 불가.
  • 필수 요소: Network selector, Withdrawal address input, Amount input, Available Withdrawal Balance, Fee, Estimated receive amount, Confirm modal, Service-restricted jurisdiction notice
Exchanges located in service-restricted jurisdictions may be restricted from deposits and withdrawals.

프론트 상태 표시: Withdraw Pending, Withdraw Processing, Withdraw Completed, Withdraw Rejected, Withdraw Failed

REJECTED 또는 FAILED 상태가 되면 차감된 Withdrawal Balance는 자동 복구되어야 한다.

6. 내부전송 Send

Send는 LONGRISE 내부 사용자 간 USDT 전송 기능이다. 외부 지갑 전송은 Withdraw이다.

Internal transfer only. Use Withdraw for external wallets.

필수 요소: Recipient identifier, Amount, Available Withdrawal Balance, Confirmation modal, Internal transfer summary

로그 필드: Sender, Recipient, Date/time, Amount, Status, Internal transfer reference ID. TxID는 표시하지 않는다.

7. 패키지 구매 잔액 처리

  • 패키지 구매는 Wallet 내부가 아니라 최상단 PACKAGES 메뉴에서 처리한다.
  • 사용 가능 잔액: Withdrawal Balance, Bonus USDT
  • Bonus USDT는 부분 사용 후 잔액이 남는 방식으로 사용할 수 없다.
  • 여러 패키지 묶음 구매 기능은 제공하지 않는다.
150 Bonus USDT -> 100 USDT package: Not available
450 Bonus USDT -> 200 USDT package: Not available
450 Bonus USDT + 50 Withdrawal Balance -> 500 USDT package: Available

8. 패키지 만기 처리

  1. active package 상태를 MATURED로 변경
  2. Package History에 Maturity 기록 생성
  3. 만기 원금을 Deposit Balance에 가산
  4. Withdrawal Balance 총액 갱신
  5. 시스템 알림 생성

9. 히스토리 사양

  • 기본 조회 기간은 최근 30일
  • 서버 페이지네이션 지원
  • Package History: Package, Date, Amount, Status
  • Recent Activity 탭은 구현하지 않는다.
  • Transfer History: Deposit, Withdraw, Deposit Pending, Withdraw Pending, Deposit Failed, Withdraw Failed, Withdraw Rejected, Send Out, Send In
  • Transfer History 컬럼: Type / Status, Date, Amount, Address / User, TxID Log
  • Earn & Reward History: Daily USDT Earning, Daily CNYT Reward, Bonus USDT Grant, CNYT to USDT Swap

INTERNAL_TRANSFER_OUT
INTERNAL_TRANSFER_IN

DAILY_CNYT_REWARD
BONUS_USDT_GRANT
CNYT_TO_USDT_SWAP
  • Withdrawal Balance = Deposit Balance + Earnings Balance
  • Bonus USDT는 Withdrawal Balance에 포함하지 않는다.
  • Package Value는 활성 패키지 총액만 포함한다.
  • 만기 패키지는 Package Value에서 제거되고 Deposit Balance에 반영된다.
  • Staked CNYT는 Available CNYT에 포함하지 않는다.

12. 프론트엔드 구현 기준

  • 기존 플랫폼의 색상, 폰트, 카드 스타일, 사이드바 스타일, 상단 메뉴 톤을 따른다.
  • 카드 제목, 금액 위치, 단위 위치를 통일한다.
  • 긴 문구는 카드 내부 줄바꿈을 만들지 않도록 축약한다.
  • 모바일 첫 화면 우선순위: 브랜드/로고, Wallet 제목, Deposit/Withdraw/Send, Assets 메뉴, Deposit/Withdraw/History/Address 메뉴, Total Assets, 자산 상세 카드

13. 배포 및 빌드 관리

GitHub Pages는 main 루트가 아니라 gh-pages 브랜치가 실제 공개 페이지일 수 있다. ZIP 내부 구버전 dist를 다시 배포하지 않는다.

배포 산출물 JS에 없어야 하는 문자열: My Wealth, AVAILABLE USDT, LOCKED USDT, RECENT ACTIVITY, LIQUID, STAKED, GROWTH

배포 산출물 JS에 있어야 하는 문자열: Withdrawal Balance, Bonus USDT, Package Value, CNYT Tokens, Assets Overview, Send to LONGRISE User

14. QA 체크리스트

  • WALLET 메뉴 클릭 시 신규 Wallet 화면이 표시되는가?
  • 구 월렛 카드가 보이지 않는가?
  • Deposit은 패키지 구매 없이 Deposit Balance에 반영되는가?
  • Package 구매 시 Withdrawal Balance가 차감되는가?
  • Bonus USDT가 출금 가능 잔액에 포함되지 않는가?
  • Bonus USDT 부분 사용 후 잔액 발생 구매가 차단되는가?
  • 패키지 묶음 구매가 불가능한가?
  • Package Value 클릭 시 Package History로 이동하는가?
  • 만기 패키지가 Deposit Balance로 자동 반영되는가?
  • Send가 내부전송으로만 작동하는가?
  • Transfer History에 입금/출금/내부전송이 통합되는가?
  • Earn & Reward History에 수익/리워드/보너스/Swap이 표시되는가?
  • PC View에서 기존 플랫폼 디자인과 통일되는가?
  • Mobile View에서 Deposit / Withdraw / Send가 상단에 보이는가?
  • 관리자 기능 또는 개발자 주석이 화면에 보이지 않는가?
